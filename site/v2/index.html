Install & run
$ git clone https://github.com/ank8dev/terminal-academy-by-ank.git
$ cd terminal-academy-by-ank
$ ./academy

That's it. No other dependencies to install.

What you'll learn

Seven levels, easy to harder

Start with your very first command and finish by connecting to a real server.

  1. 1

    First steps

    Open the terminal, run your first commands and find your way around.

  2. 2

    Files & folders

    Create, move, copy, rename and delete — without a mouse.

  3. 3

    Reading & searching text

    Peek inside files and search for exactly what you need.

  4. 4

    Permissions

    Understand who is allowed to read, write and run files.

  5. 5

    Processes

    See what's running on your computer and how to control it.

  6. 6

    Networking

    Learn the basics of how computers talk to each other.

  7. 7

    Servers & SSH

    Log in to remote machines securely with SSH.

How it works

Three steps. Real commands.

  1. 1

    Start with one command

    Clone the project and run ./academy. It works on macOS and Linux with Python 3.9 or newer.

  2. 2

    Practice in a sandbox

    Each lesson gives you a task. You type real commands in a safe practice folder, so you can experiment freely.

  3. 3

    Get feedback & hints

    The app checks your result and nudges you with hints. Your progress is saved locally on your computer.
