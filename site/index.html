// How it works

Three steps, all in your terminal

  1. 01

    Run it

    Clone the repository and start ./academy. One command, nothing else to install.

  2. 02

    Practice for real

    Each lesson gives you a task. You type real commands inside your own practice folder, the sandbox.

  3. 03

    Get instant feedback

    The app checks every step, gives hints when you are stuck, and explain <command> shows short notes. Progress is saved on your computer.

// Safe by design

Real commands, sensible guard rails

You learn on your real computer, so we built in protection against the usual beginner accidents.

  • sandbox

    A practice folder for every lesson

    Lessons happen inside a separate folder that is set up for you, so your own files stay out of the way.

  • blocklist

    Dangerous commands are stopped

    Commands that can damage a computer, like sudo, disk tools or shutdown, are blocked with a short explanation.

  • no root

    No admin rights needed

    Everything works as a normal user. The app refuses to start as root unless you explicitly ask it to.

  • no data

    Nothing leaves your computer

    No servers, no accounts, no analytics. Your progress is a small file on your own machine.

To be clear: the sandbox protects against accidents, not deliberate misuse. Commands are real and run as your user — that is what makes the practice real.
