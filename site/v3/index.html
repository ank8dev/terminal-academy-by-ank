🎮 How to play

  1. 01

    Start the game

    Clone the repo and run ./academy in your terminal. One command, no extra installs.

  2. 02

    Complete the quest

    Every lesson gives you a mission. Type real commands inside a safe practice folder — the sandbox.

  3. 03

    Get checked, level up

    The app checks your result and drops hints if you're stuck. Progress is saved on your computer.
