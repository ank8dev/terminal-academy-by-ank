> Learn the terminal by actually using it.

A free, open-source app that teaches teens and beginners the command line — right inside your own terminal.

// install & run (macOS, Linux · Python 3.9+)

$ git clone https://github.com/ank8dev/terminal-academy-by-ank.git
$ cd terminal-academy-by-ank
$ ./academy
[ View on GitHub ] [ See the lessons ]

## What you'll learn

Seven levels, from your very first command to logging into a server.

  1. 01

    First steps

    Open a terminal, run commands, find out where you are.

  2. 02

    Files & folders

    Move around, create, copy, rename and delete.

  3. 03

    Reading & searching text

    Look inside files and find exactly what you need.

  4. 04

    Permissions

    Who can read, write and run a file — and why.

  5. 05

    Processes

    See what is running on your machine and control it.

  6. 06

    Networking

    The basics of how your computer talks to others.

  7. 07

    Servers & SSH

    Connect to remote machines like a pro.

difficulty [░░▒▒▓▓█] easy → harder

## How it works

  1. step_1

    Run one command

    Clone the repo and start ./academy. Works on macOS and Linux with Python 3.9+. No other dependencies.

  2. step_2

    Type real commands

    Each lesson gives you a task. You do it in a safe practice folder (a sandbox), so your other files are protected from mistakes.

  3. step_3

    Get checked & hints

    The app checks your result and gives hints when you're stuck. Progress is saved locally — pick up any time.

## Who it's for

> teens

Roughly 13–18 and curious how computers really work? Learn the tool that developers, hackers and sysadmins use every day.

> parents & teachers

Free, open source, no account and no tracking. Lessons run in a sandbox, and progress stays on the learner's own computer.

> beginners

Never opened a terminal? Start at level one. Clear tasks, instant feedback, and hints along the way.
