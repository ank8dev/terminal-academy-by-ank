# Security Policy

## Supported versions

Terminal Academy is in active development. Security fixes are made on the
latest version of the `main` branch.

## Reporting a vulnerability

**Please do not report security problems in public issues.**

Report them privately using GitHub Security Advisories:

1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Describe the problem, how to reproduce it, and what impact it could have.

If you can't use that form, contact the maintainer
[@ank8dev](https://github.com/ank8dev) on GitHub.

We will reply as soon as we can, keep you updated while we work on a fix, and
credit you when the fix is released (unless you prefer to stay anonymous).

Because Terminal Academy runs commands in a learner's terminal, we take issues
like unsafe lesson commands, files being changed outside the practice area, or
code execution from lesson files especially seriously.
